# 부캉이 직캠 챌린지 (Bukangi Shark Photo Hunt)

2026년 9월 18일 ~ 10월 21일 부산 북항친수공원 수로에 머문 흑상어 '부캉이' 사건을 모티브로 한 모바일 우선 픽셀아트 촬영 게임입니다.

## 바로 실행
```bash
npm install
npm run dev
```
