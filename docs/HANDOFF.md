## 4. 기능 명세 (현재 구현 상태)

### 4.1 화면 흐름
`TitleScreen` → (Day 선택 + 닉네임 + 시작) → `PlayScreen`(90초) → `ResultScreen` → 다음 날 / 재도전 / 처음으로.
상태 머신은 `src/pages/home.tsx`의 `HomePage`가 소유합니다(`screen: "title" | "play" | "result"`).

### 4.2 타이틀 화면
- 부캉이가 헤엄치는 **어트랙트 지도**(실시간 캔버스)
- **부캉이 34일 달력**: 7열 캘린더(9/18 금요일 시작), 클리어 ✓ / 잠김 🔒 / 태그 색 점(연휴·작전·뉴스·작별·주말), 선택일 상세(제목·설명·목표·내 최고)
- 닉네임(최대 12자) + "Day N 촬영 시작"
- **장비 강화소**(아이템 토글, 장비 4종 강화, 굿즈 박스)
- 규칙 카드 6장, **촬영 도감**, **팀 랭킹**(샘플 8명 + 내 기록)

### 4.3 플레이 화면 (세로 9:16)
- 상단 HUD: 남은 시간, 조회수, 배터리 미터 / Day 정보, 상태 배지(작전 중·다리 위·충전 중·콤보) / 목표 달성률 바
- 지도: 180×320 논리 픽셀 캔버스(`image-rendering: pixelated`) + HTML 라벨 오버레이(보도교 1~5, 명당, 관리동 카페, 부산역, 북항 바다, 문화공원, 오페라하우스)
- **이동**
  - 지도 왼쪽 55% 영역에서 드래그 → **세로 슬라이드 패드**(플로팅, 반투명). 위로 밀면 부산역 쪽(s+), 아래로 밀면 바다 쪽(s−). 밀수록 빠름(최대 46px, 데드존 12%). 손 떼면 정지. 대기 시 왼쪽 아래에 35% 불투명 고스트 패드
  - 짧게 탭(8px 미만 이동) 또는 오른쪽 45% 탭/드래그 → 가장 가까운 산책로 지점으로 이동
  - 키보드: ↑/→ 부산역 쪽, ↓/← 바다 쪽, Space 셔터 (지도 영역 포커스 시)
- **다리 스냅**: 정지 상태에서 보도교 ±0.035(s) 이내면 자동으로 다리 위로 이동. 근처(±0.06)면 다리 노란 테두리 깜빡임. 다리 위: 프레임 ×1.35, 조회수 ×1.3, 안전요원 허용 7초
- **셔터**(오른쪽 아래, pointerdown 즉시 발사, 0.5초 쿨다운) / 상태 텍스트(프레임 IN, 부캉이 찾는 중, 촬영 제지 중, 부기가 가림!)
- 효과음·BGM·진동 토글 버튼 3개
- 팝업 토스트(최대 3), 실시간 댓글창(우하단, 최대 3줄), 안전요원 게이지(상단)

### 4.4 방해 요소 / 이벤트
| 요소 | 동작 |
|---|---|
| 구름 인파 | 위치별 밀도 → 이동속도 `×(1−0.65×밀도)`. 명당(s 0.10~0.30)이 가장 붐빔. Day별 인파 배율 |
| 안전요원 호루라기 | 한 자리 정지 시간이 한도(명당 4.5초 / 다리 7초 / 그 외 8초) 초과 → 2초 촬영 금지 + 밀려남 + 콤보 리셋. 카페 충전 중엔 면제 |
| 폰 배터리 | 대기 소모 0.45%/초, 촬영 5%/장 (보조배터리로 감소). 관리동 카페(s 0.6 ±0.03)에서 +16%/초 충전 |
| 해경 작전 | 작전일(Day12 워터펌프, Day15 특수 그물)에만. 작전 중 부캉이는 주로 잠수, 바다 쪽으로 밀리다 출구에서 유턴 → 작전 종료 시 "복귀 점프". 작전 중 포착 ×2 |
| 3차 작전 (Day34) | 폰툰+그물 라인이 s 0.97→0.04로 80초에 걸쳐 이동, 부캉이는 그물 앞쪽으로만 이동 가능. 그물이 출구 근처(<0.12)에 오면 부캉이가 바다로 나가 사라짐("잘가라, 부캉아") |
| 부산갈매기 '부기' | 판당 Day별 1~3회(약 15/44/73초, 작전 시간 회피). 1.1초 날아와 프레임 중앙에 착지, 최대 6초. 플레이어가 산책로를 0.05(s) 이상 움직이면 쫓아냄. 앉아 있을 때 촬영 → "부기 난입 컷"(300~600회, 콤보 리셋, 도감 등록) |
| 출구 앞 유턴 | 부캉이는 s<0.045(출구)에서 반드시 유턴 (실제 사건의 "출구 코앞에서 유턴" 재현) |

### 4.5 점수
```
조회수 = round( (900 + 2600 × 중앙도) × 배수 × (1 + 0.25 × min(콤보, 8)) + rand(0~99) )
중앙도 = 1 − (상어와 프레임 중심의 수로 거리 / 프레임 크기)
배수 = 상태(실루엣 1 / 지느러미 1.6 / 점프 5) × (작전 중 2) × (다리 위 1.3) × 망원렌즈 배율
```
광고수익 = 판 총 조회수 ÷ 20 (원)

### 4.6 결과 화면
- 클리어/미달 배너, Day 34 클리어 시 **작별 엔딩 + 위촉장**
- **결과 카드**(날짜·닉네임·Day 제목·조회수·등급 문구·광고수익·베스트 샷 폴라로이드·순위/촬영수/성공률·새 도감·해시태그) → **PDF 저장**
- 다음 날 / 재도전 / 처음으로, 장비 강화소, 도감(NEW 강조), 팀 랭킹(내 기록 하이라이트)

### 4.7 도감 사진 보기/저장
- 사진이 있는 도감 칸을 **450ms 꾹 누르기**(키보드는 Enter/Space) → 도감 위에 크게 열림(120×120 맵픽셀 크롭 ×4배)
- **PNG 저장**(다운로드 버튼 또는 이미지 길게 눌러 기기 저장) + **사진 카드 PDF 저장**

## 6. 게임 엔진 구조 (`src/lib/park-engine.ts`)

### 좌표계
- 논리 해상도 **180×320** (세로). CSS로 확대 + pixelated.
- 수로 중심선 `CHANNEL`(폴리라인): 좌하단 바다 출구(14,318) → 원형 문화공원(중심 100,200 / 반지름 66) 왼쪽·위쪽 호 → 오른쪽 위 부산역 방향 직선(161,12).
- **모든 위치는 수로 길이 비율 `s ∈ [0,1]`** 로 표현 (0 = 바다 출구, 1 = 부산역 끝).
  - `channelAt(s)` → 수로 중심점 + 접선(tx,ty) + 왼쪽 법선(nx,ny)
  - `promenadeAt(s, extra)` → 법선 방향 13px(+extra) 오프셋 = 산책로
  - `nearestPromenadeS(x,y)` → 탭 좌표 → s (241 샘플)
- 플레이어 `g.ps`(현재 s), `g.target`(탭 목표 s), `g.steer`(패드 입력 −1~1)
- 프레임 중심 = `channelAt(g.ps)` (플레이어 앞 수면)

### 루프
`PlayScreen`의 `requestAnimationFrame` 루프 → `step(g, dt, emit)` → `render(ctx, g)` → 100ms마다 HUD 상태(`setHud`) 갱신. `dt`는 최대 0.05초로 클램프.
엔진은 React와 무관한 순수 함수/가변 객체이며, 이벤트는 `emit({ text, tone, kind })` 콜백으로 UI에 전달됩니다. UI는 `kind`로 효과음·진동·댓글을 매핑(`EVENT_FX`).

### Game 주요 필드
| 필드 | 의미 |
|---|---|
| `gear` | `{frame, drain, lens, speed, levels}` (park-gear의 `gearFrom()` 결과) |
| `ops`, `final`, `netS`, `gone`, `crowdMul` | Day 설정에서 온 작전 창, 최종일 여부, 폰툰 위치, 부캉이 퇴장 여부, 인파 배율 |
| `shark` | `{s, dir, speed, state(swim/fin/dive/jump), until, jumpStart, lastJump, nextTurn}` |
| `gull` | `{phase(none/in/perch/out), t0, shake, x, y, times[]}` |
| `still`, `lockUntil`, `guardUntil` | 정지 누적, 촬영 금지, 안전요원 표시 |
| `battery`, `views`, `shots`, `hits`, `combo`, `hitTimes[]` | 자원/점수 |
| `crowd[]` | 군중 150명 (60% 명당 배치), 시간 따라 표시 비율 35%→100% |

### 상어 AI (`updateShark`)
- 상태 만료 시 확률 전이: 점프 10%(직전 점프 9초 경과 시) / 잠수 14% / 지느러미 32% / 실루엣 나머지. 작전 중엔 잠수 75%.
- 5~11초마다 방향 재설정: 55%는 명당 중앙(관종 성향), 나머지 랜덤. 속도 0.03~0.06 s/초.
- s<0.045 유턴(15초마다 "출구 코앞에서 유턴!" 이벤트), s>0.97 반전.

### 렌더 순서
`drawMap`(잔디·철도·부산역·주차장·바다·산책로·수로·물결·원형공원·오페라하우스·보도교·카페) → `drawOp`(해경 보트/펌프/그물, Day34 폰툰) → `drawCrowd` → `drawShark` → `drawPlayer`(다리 하이라이트·안전요원·뷰파인더) → `drawGull` → 플래시.

### 스냅샷
도감/베스트 샷은 촬영 순간 `structuredClone(g)`를 저장하고, 결과·도감 화면에서 같은 `render()`로 다시 그려 크롭 표시합니다(이미지 파일 저장 아님).
